# 樽の種類と風味への影響（学習メモ）

ウイスキーの香味の多くは熟成中に樽から得られると言われます。ここでは代表的な樽を
ごく簡単に整理します（数値はおおよその目安です）。

## バーボン樽（アメリカンオーク）

容量は約200リットル。バーボンの熟成に一度使われた樽で、内側を強く焦がしてあります。
バニラ、ココナッツ、はちみつのような甘い香りがつきやすく、色は淡い金色になります。
世界で最も流通量が多い樽です。

## シェリー樽（ヨーロピアンオーク／スパニッシュオーク）

容量は約500リットル（バットと呼ばれる）。オロロソやペドロヒメネスなどのシェリーを
熟成させた樽で、干しぶどう、イチジク、チョコレートのような濃厚な風味と、
赤みがかった濃い色をウイスキーに与えます。タンニンが強く出ることもあります。

## ミズナラ樽（ジャパニーズオーク）

日本原産のオーク。木目が粗く液漏れしやすいため扱いが難しい一方、長期熟成で
白檀や伽羅のような香木を思わせる独特の香りが出ます。

## 用語

- **ファーストフィル**：ウイスキーの熟成に初めて使う樽。樽の影響が強く出る
- **リフィル**：2回目以降に使う樽。影響が穏やかで、原酒の個性が残りやすい
- **チャー／トースト**：樽の内側を焼く処理。チャーは強く焦がし、トーストは軽く焙る
